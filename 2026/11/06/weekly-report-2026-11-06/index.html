④ Agent 基建从「能力」转向「手艺」——记忆（claude-mem）、编排（ECC / superpowers）、控制台（t3code）、IDE（thinkrail）、桌面操控（agent-desktop）、需求澄清（mattpocock/skills）各自补齐一个环节；
⑤ Skill 的 token 成本被摆上台面——一次设计迭代 30 ~ 45 分钟、几十万 token，skill 本身是文本，贵的是它触发的推理调用，预算要看模型账单而不是安装命令；
⑥ 本周最大受益方向仍是前端——设计、SEO、界面重建三类 skill 全部指向「从需求 / 参考图到可交付页面」这条链路。

二、阮一峰周刊 · 第 418 期（方向精选）

头条：《如果科技停止在21世纪初》

有人写了一篇文章，明确希望回到 21 世纪初那几年，而且人类文明就停在那里。他的判断是：技术不是越现代越好，而是要与人类平衡，21 世纪初恰好是科技与现实生活的完美平衡点——够方便，但人还有生活的主导权。分界线是 2007 年 6 月 29 日，iPhone 发布那天；最佳时期是 2003 年左右。

他的理由集中在「不上瘾」和「可离线」：功能机打电话、发短信、玩贪吃蛇、看简单网页就够用，摄像头很烂但照片也能看，最重要的是你不会每隔几十秒低头滑一下；社会主流还是人与人的互动，而不是人与机器的互动。那时上网是一种选择，你可以完全离线生活；现在不行了，聊天、约会、购物、娱乐、地图都变成一个个 App，做任何事都要先打开对应 App。阮一峰的落点是：技术曾经只是工具，现在成了生活方式；尤其 AI 造出了超越人类的智慧机器，让大多数人类技能贬值，「但愿它能把我们带到一个更好的地方」。

本周软件：MonkeyAI（百智办公）

开源的私有化企业 AI 工作台（chaitin/monkeycode，约 5000 星）。所有员工通过它统一使用 AI，可指定模型、共享知识库 / 技能 / MCP，数据全部留在本地，带权限管理和使用统计后台。自带办公（文件、文档、表格、PPT）、编程、设计（平面 / 交互 / 短剧）三个场景，不需要外部工具；客户端覆盖 Web、iOS、安卓、Mac / Win / Linux，甚至鸿蒙；服务端只要单核 CPU + 1G 内存的 Linux 机器。10 人以内免费，超过需购买授权。对想在小团队里落地「自托管 AI 工作台」的人，这是本周最值得动手试的一个。

JS 框架的 AI 成本（本周最该看的前端内容）

Nolan Lawson 做了个测试：让 AI 模型用不同的 JS 框架完成同一个编程任务，统计每个框架的费用、耗时、消耗的 Token。结论很干脆：前三名基本固定，只是名次会换——Hono + htmx、Astro、Nuxt；而所有比较的最后一名，始终是同一个框架：Angular。

这条结论的意义不在排名，而在选型维度：当代码主要由 agent 写，框架的「AI 使用成本」就成了和性能、生态并列的指标。模板越啰嗦、隐式约定越多、上下文越重，agent 的账单和出错率就越高。

科技动态（方向相关）

  • JetBrains 首次亏损：2025 年亏损，是这家公司成立 20 年来第一次。IntelliJ IDEA 是 Java / Kotlin 开发的事实标准，连它都亏，只有两种可能——AI 编码盛行让传统 IDE 需求变少，或为 AI 投入巨资。无论哪种，都指向传统 IDE 正在衰落。
  • Facebook 限制外链：免费用户每月发言最多带两个外部链接，超出要开付费会员。平台越来越不愿意给外部网站导流，只想把用户关在自己站内。

工具（方向精选）

  • SOML（soml-lang/soml）——想取代 JSON 的数据文件格式，号称消掉 JSON 大多数缺点，基本是 YAML 的简化版，多语言实现。配置文件 / 数据交换场景值得关注。
  • Casnode（casnode/casnode）——Discourse 风格的开源论坛，Go + Next.js，数据库默认 SQLite。想自建社区又不想上重型栈的可以直接看。
  • Linkit（blue-idea/linkit）——浏览器书签的桌面管理器，Go + Wails + SQLite，支持本地语义向量检索、404 死链检测、知识图谱。技术栈和「本地优先 + 语义检索」的组合很有参考价值。
  • Crossbow（Richard-Zhang1019/Crossbow）——开源的代理桌面客户端，双内核一键切换。
  • florilegium——LaTeX 插件，在页面空白处生成植物图案；作者点出这个概念完全可以移植到网页，是个不错的前端小实验题目。
  • 澜姿（wzc520pyfm/gen-ai-pose-image）——可微调的人体姿态 / 服装 / 表情模板，供 AI 套用到图片上；halfsize 则是把视频压到指定大小的命令行工具。
