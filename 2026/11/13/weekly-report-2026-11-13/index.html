本周热点主题

① Agent Skills 依旧统治周榜——前 10 里有 6 个是 skill 或围绕 skill 的基建（Cloudflare 安全审计、mattpocock 需求澄清、anthropics / google 官方库）。比拼点已经不是「哪个模型更强」，而是「谁能给 agent 更硬的手艺」。

② 前端最佳实践开始由浏览器厂商直接供给 agent——Chrome / Edge / Firefox / MDN 联合出 modern-web-guidance，等于把「现代 Web 怎么写」从博客文章变成 agent 能检索、能扫代码库的规范源。这是本周对前端最重要的结构性变化。

③ 设计系统同时为人和 agent 设计——Meta astryx（React 19 + StyleX，无需构建插件）和 Vercel ui（行为库 + 多框架适配）都在强调「agent 能直接读懂、直接拼装」。组件库的说明书，正在变成 skill 文件。

④ 云端依赖往回搬——aws-emulator 把 AWS 测试搬回本机，每测试一个隔离实例、每版给保真度评分，是「本地优先」在测试环节的落地。

⑤ 操控层在补齐——agent-desktop（桌面）、agent-browser（浏览器）、OpenMausBot（整机 VM），三条路线同周上榜，说明瓶颈已经从「模型会不会」转到「怎么安全地让它动手」。

⑥ 可解释性成为卖点——auto-ontology 讲确定性查询与可解释推理，rea 讲每条结论的证据与局限。agent 越能干，证据链越值钱。

二、阮一峰周刊 · 第 419 期（方向精选）

头条：《机房来了，写字楼走了》

有博主去内蒙古乌兰察布拍机房工地，被震住了：曾经的草原上聚了几万建筑工人，一个内陆地级市已有 100 多个数据中心（含在建），全国主要 IT 与算力公司几乎都在那里有机房。成因他总结得挺准：离北京直线 240 公里、光纤往返延迟只有 4.2 毫秒；有效风场占全国十分之一、年日照超 3200 小时，绿电便宜；年均气温 4.3℃、一年十个月可以直接用室外冷空气散热；最初地价一亩才几万元。

真正让阮一峰停下来的是那句话：「写字楼会越来越不值钱，智力产出正转移到这些数据中心。」他的推论是——机房是新的写字楼，是智力成果的主要生产场所；城市的办公地产不看好了，写字楼会过剩、租金下跌，前些年到处建的 CBD 以后可能没这个概念，乌兰察布那样的「机房之城」才是 AI 时代的 CBD。

这一期对工程师更重要的其实是第二篇：奈奎斯特极限

奈奎斯特极限是信号处理定律：想还原一个变化的信号，采样频率至少得是最高频率的两倍，否则失真。有人把这套逻辑搬到 AI 编程上：

阅读代码的频率，必须至少是代码改动频率的两倍，否则无法理解代码。

假设 AI 每天改 5 次代码，你每天至少要读 10 次，否则很快就会丧失对仓库的理解。有些公司为了提速度不停加 AI 使用频率、每天大量提交，但读代码的频率没同步提升，远低于 2 倍——它们已经进入了「信号失真」状态，对自己的产品不再了解。这条定律比任何工具评测都值得贴在团队墙上。

文摘：《我们公司使用 AI 编程一年了》——和上面那条互相印证

一年前公司要求所有编程都通过 AI，手写代码要给出理由。前六个月一切顺利，交付量比以往任何时候都多。到了现在：代码库变成原来的 3 倍，没人能解释其中大部分功能的运作原理；AI 一遍遍重新实现别处已有的工具函数，同一个功能在系统里有 4 个版本；两个最活跃的程序员，一个辞职、一个被「优化」；AI 对每个提交都留评论，但已经没人判断得了哪条重要，于是全被忽略。本月领导开始暗示「可以适当多手写一些」——但一半人已经一年没写过像样项目，作者花两天手写了一个 2024 年一下午就能完成的程序。

科技动态（方向相关）

  • 联想指纹加密 U 盘被拆穿：必须先过指纹才能读写，网友拆开后发现里面就是一块 SD 卡，取下 SD 卡加密就消失。加密措施成了商业噱头；顺带两个工程教训——双重电路拖性能，SD 卡不适合长期存数据。
  • 谷歌 Gboard 年度创意键盘：今年是「流水线键盘」，四排按键各骑一条传送带循环滚动，手指不动让键来找你，概念像回转寿司。纯硬件创意，但对交互设计是个有意思的极端样本。

文章（方向精选）

  • 《我如何阻挡 AI 爬虫》：作者站点流量暴涨全是机器人，他的办法是在网页里放一个肉眼不可见的链接，凡是访问该链接的 IP 一律封禁——一个成本极低的「蜜罐」。做个人站点的可以直接抄。
  • 《Node.js 27 的新特性》：从明年起 Node.js 每年只发一个大版本、每个版本都是 LTS，27 版已在测试。发布节奏变化会影响团队的升级计划，值得提前知道。
  • 《我放弃 Claude Code，改用 Pi》：作者讲清了不满意在哪、最后为什么换，工具选型的第一手材料。
  • 《Fable 5.2 一晚生成了我侄子的梦想游戏》：拿草图 + 口头设想，一晚生成 12 个关卡且第一次就能玩，AI 生成游戏的当前水位。
  • 《黑苹果重生》：苹果转向 M 系列后黑苹果一度废掉，现在靠 AI 辅助移植又慢慢复活。

工具

  • BoopFace——网页里插 SVG 机器人脸组件的库，18 种表情和互动，专为 AI 聊天机器人和 Agent 界面准备。做 AI 产品前端的话，这类「人格化组件」会越来越多。
  • Cyber API——Rust + GPUI 的 API 调试桌面客户端，GPU 直接绘制，绕开 Electron 的内存与卡顿。Electron 替代路线又多一个样本。
  • kan.ban——JS 写的开源看板，Trello 替代品；Beamlynx——数据库客户端，删一行数据会找出所有指向它的外键，不留悬空引用（非商业免费）。
  • rVPN——开源加密通信协议，目标是与 HTTPS 流量无法区分；dnsglobe——一条命令给全球 34 个公共 DNS 测速，找出你这里最快的那个。
  • Melarka（本地音乐流媒体服务器，支持 YouTube 音乐与多账号）、MD-Vault（用 Markdown 存 2FA 时间码的 Web 应用）、zlib（Z-Library 命令行客户端）、Procexp-Mac（把 Process Explorer 搬到 Mac）、Window Sweaters（给 Mac 窗口穿毛衣）。
