一、本周 4 条 · 方向相关

1. ChromeDevTools/chrome-devtools-mcp（TypeScript）

把 Chrome DevTools 的能力暴露给编码代理：代理自己就能开性能面板、看网络请求、读 console 报错，不用人手截图贴给它。

看点在于调试链路的位移——过去是“我发现问题，描述给 AI”，现在是“AI 自己看到问题”。对前端来说，这比多一个代码补全工具更实质。

判断：待判断（2026-11-27）

2. GoogleChrome/modern-web-guidance-src（TypeScript）

Chrome 团队维护的 web 平台最佳实践技能包，源码仓库。上期榜单里出现过同源的 modern-web-guidance（Chrome/Edge/Firefox/MDN 联合维护），本周上榜的是它的 src 仓库，覆盖 view transitions、container queries、Popover API 这类新东西。

看点在于“官方把最佳实践写成 agent 的默认知识”，而不是让人去翻 MDN。

判断：待判断（2026-11-27）

3. ag-ui-protocol/ag-ui（TypeScript）

Agent-User Interaction Protocol：定义 agent 与前端之间的事件流（JSON Schema + TS/Python/.NET SDK），把 token 流、工具调用、human-in-the-loop 统一成一套格式。

看点在于前端多了一层新接口——以前前端对接的是 REST/GraphQL，现在要对接的是“流式事件 + 可中断的工具调用”。

判断：待判断（2026-11-27）

4. meta/astryx（TypeScript）

Meta 开源的、可完全定制的设计系统，自我定位是 “agent ready”。

看点是设计系统的交付对象变了：以前给人写文档、给设计师出组件，现在还要让代理能正确选组件、正确用 token。

判断：待判断（2026-11-27）

二、其余上榜 · 一句话交代

  • 强相关但没单列：backnotprop/plannotator（给 agent 做决策、计划、批注、代码审查的工作台）、dream-num/univer（前端表格 / Office SDK）、alibaba/open-code-review（Go，混合式代码审查，阿里内部量级验证）。
  • 技能包同类扎堆：google-labs-code/stitch-skills、obsidianmd/obsidian-skills、mvanhorn/last30days-skill、tradermonty/claude-trading-skills、kajisho5/ffmpeg-skill。方向各不相同，共同点是把“某类领域知识 + 工具”打包成代理能直接加载的资产。
  • 弱相关 / 已过滤：n8n-io/nod（个人 agent 跑腿：追发票、约电话、退订阅）、we-promise/sure（个人理财）、pookjw/HermesEnabler（Apple Watch 表盘）。都属于消费品或生活类，不进主体。

三、热点主题归纳

1. 技能包进入“官方背书 + 垂直分工”阶段。 上周还是通用 Agent Skills 扎堆，本周 Chrome、Meta、Obsidian、Google Labs 各自出官方版本；覆盖面从“怎么写代码”变成“怎么用某个具体平台”。

2. 前端正在被协议化。 一边是 ag-ui 定义 agent 与前端的标准事件流，一边是 DevTools 被代理接管。前端的调用方从“人点按钮”变成“代理调接口”，这会影响组件怎么设计、状态怎么暴露。

3. 瓶颈已经挪到“审代码”。 榜单里 plannotator、open-code-review、上一期的 Claude-BugHunter 都在解决“审”，与周刊引用的哈佛结论（AI 编码把瓶颈从写代码转到代码审查）互为印证。这条对你是最直接的信号：团队里下一个值得投入的工具，大概率不是生成代码的，而是审代码的。
